# Sotto base vs Sotto+LoRA — LEAK-FREE held-out eval

**This supersedes `sotto_plus_ours_SUMMARY.md`, which was contaminated**
(its 8 "course" phrases were `COURSE_PAIRS[0:8]`, i.e. verbatim training rows).

## Method (no leakage)

- **Eval set:** 36 phrases generated by the **Grok CLI** (`gen_holdout_eval.py`)
  on deliberately *different* topics (dry cleaning, lasagna, potting soil,
  Vitest, risotto…). Training topics were listed as banned.
- **Leak gate:** every eval raw/clean string is normalized and checked against
  the entire `sotto_ft` train+valid+test set. Runtime re-check aborts the eval
  if anything overlaps. Result: **0/36 overlap.**
- **Adapter:** `sotto-lc-ft-clean` — fresh LoRA on
  `juanquivilla/sotto-cleanup-lfm25-350m-mlx-5bit`, 600 iters, LR 5e-6, 8 layers
  (val loss 3.59 → 0.93). Same train data as before; **only the eval changed.**
- **Grading:** Grok-as-judge (`eval_holdout.py`), strict per-tag rubric
  (course = honored the self-correction AND preserved meaning AND not over-short).
- Greedy decode (temp 0), Sotto native `### Input/### Output` format.

## Results (held-out, Grok-judged)

| Model | Course | Light | Preserve | Latency |
|-------|-------:|------:|---------:|--------:|
| Sotto base   | 10/16 | 12/12 | 6/8 | ~50 ms |
| **Sotto+ours** | **13/16** | 12/12 | **7/8** | ~60 ms |

**Honest readout**
- The LoRA **does generalize** to unseen course-correction phrasing: 10→13/16.
  This is a real but *modest* gain — not the fake 3/8→8/8 from the leaked run.
- Light cleanup: tie at 12/12 (both already strong).
- Preserve: 6→7/8; the one `+ours` "miss" is only number normalization
  ("seven"→"7"), arguably a false negative from the strict judge.

**Where `+ours` still fails (3/16 course)**
- Over-short: drops a clause ("Take the inland route" — lost "to the cabin").
- One 5-bit corruption: "simmer" → "Smear" (base-model quantization artifact,
  not a training issue).
- One kept the retracted item ("overnight shipping").

Base's failures are the classic pattern the LoRA fixes: it keeps the retracted
item and echoes the "not X, Y" meta-phrase.

## Reproduce

```bash
cd bench && source .venv-polish/bin/activate
# 1. (re)generate a fresh leak-free eval set via Grok
python polish_finetune/gen_holdout_eval.py
# 2. train clean adapter (data unchanged)
mlx_lm.lora --model juanquivilla/sotto-cleanup-lfm25-350m-mlx-5bit --train \
  --data polish_finetune/data/sotto_ft --fine-tune-type lora --iters 600 \
  --learning-rate 5e-6 --num-layers 8 --batch-size 2 --max-seq-length 512 \
  --adapter-path polish_finetune/adapters/sotto-lc-ft-clean --seed 42
# 3. eval base vs +ours, Grok-judged, with runtime leak gate
python polish_finetune/eval_holdout.py
```

Full per-item verdicts: `results/sotto_holdout_clean.json`.
